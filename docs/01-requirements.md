# 需求分析

> 状态：已确认（2026-07-27）。分支 `202607271440-init`。
> 修订（2026-07-27）：取消三类提醒区分，仅保留单一「休息」提醒；新增全局快捷键需求。

## 定位

轻量 Windows 桌面健康提醒工具，面向电脑办公用户。无在线系统、无用户系统，纯本地运行。

## 环境

- 开发环境：Ubuntu 22.04 (WSL)，仅作为编码/版本管理环境
- 运行/调试环境：Windows 11（GUI、托盘效果必须在 Windows 侧验证）

## 功能需求

### 1. 提醒调度器

- **只有一种提醒：休息**（不区分远眺/眼睛休息/活动身体）
- 可配置：间隔分钟（可自定义）、休息时长（可自定义）、启用开关
- 每次休息结束后重置计时器
- 支持全局暂停/恢复提醒（托盘菜单）
- 下一次休息倒计时对用户可见：托盘 tooltip 悬停显示 + 设置页实时刷新

### 2. 休息进度提示界面

- **形态（默认假设）：小浮窗置顶显示；可配置切换为全屏遮罩模式**
- 内容：简约加载进度条风格的进度指示，显示剩余时间
- 提供「提前结束」操作（记录为 stopped）
- **扩展要求：用户可导入自定义进度指示组件**——需定义组件契约（输入：进度 0~1、剩余秒数、状态）与用户目录下的加载机制，校验失败时回退默认样式

### 3. 休息记录

- 每次休息落一条记录：触发方式、计划时长、实际时长、结果（done / stopped）、时间戳
- **手动休息（已确认）：仅手动触发**——托盘菜单或快捷键「立即休息」，走正常休息流程并记录（trigger = manual）
- **呈现（已确认）：记录列表 + 简单统计**（今日完成次数、连续坚持天数）

### 4. 系统托盘（主入口）

- Windows 右下角托盘图标，右键菜单：打开设置、立即休息、暂停/恢复提醒、查看记录、退出
- 设置界面为小窗口、护眼解压配色（低饱和绿/米白、圆角、柔和对比）

### 5. 跟随系统自启动（已确认）

- 设置页提供「跟随系统自启动」开关，可随时开/关，默认关闭
- 开关状态持久化在 settings.json，变更即时生效

### 6. 全局快捷键（已确认）

- 常用功能可各自配置一个**系统级快捷键**：立即休息、暂停/恢复提醒、打开设置
- 每个功能的快捷键均可自定义按键、可留空（**留空即关闭**，满足"支持关闭"）
- 设置页提供按键录制输入；快捷键冲突（被系统/其他应用占用）时提示
- 快捷键触发的行为与托盘菜单一致

### 7. UI 自定义能力

- 进度指示组件、设置窗口风格均预留自定义组件扩展能力
- 用户可编写的组件格式是技术栈选型的关键约束

## 非功能需求

- 轻量：常驻内存尽量小，CPU 基本只跑定时器
- 单实例运行
- 纯本地存储，无网络依赖
- 安装形态：单 exe 绿色版优先

## 数据模型草案

```
settings.json:  { break: {intervalMin, durationSec, enabled},
                  hotkeys: {breakNow, togglePause, openSettings},   // accelerator 字符串或 null
                  global: {paused, autostart, overlayMode, theme} }
logs/*.jsonl:   {ts, trigger: scheduled|manual,
                  plannedSec, actualSec, result: done|stopped}
```
